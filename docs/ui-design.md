# 네이티브 화면 구성

Codex Desktop의 모습에 최대한 가깝게 해 달라는 후속 요청에 맞춰 Rust 네이티브 화면을 정리했다. 초기 목업에서 제안했던 배치와 현재 구현을 구분하며, 전체 제품 기능의 완료 여부는 [검증 현황](validation.md)을 따른다.

## 현재 배치

- 왼쪽 사이드바: 새 작업·작업 검색·응답 필요, 프로젝트 아래 작업 목록, 하단 기억·설정. 파일 탐색으로 전환하거나 사이드바 전체를 접을 수 있다.
- 상단: 현재 작업명과 `대화 / 편집` 전환, 코드 미리보기·실행 패널 제어. 실행 대상 정보는 대화 입력창 아래에서 확인한다.
- 대화 배치: 읽기 폭을 제한한 대화와 입력창을 가운데 둔다. 사용자 메시지는 옅은 말풍선, assistant 답변은 Markdown 본문으로 표시한다. 도구 결과는 접혀 있는 항목을 펼쳐서 확인한다.
- 입력창: `Ctrl+Enter` 또는 보내기 버튼으로 요청한다. 작업 중 추가 요청은 다음 작업으로 예약된다. 모델 이름은 연결 설정을 열고 `+`는 파일 탐색을 연다.
- 편집 배치: 코드 영역을 넓게 사용하고 충분한 폭에서는 오른쪽 대화를 함께 표시한다. 좁은 창에서는 대화·편집을 전환해 사용한다.
- 실행 패널: 기본적으로 닫혀 있다. 상단 터미널 버튼이나 응답 필요 항목으로 열고, 명령·승인·실행 작업·언어 분석·터미널·Git·도구 연결 탭을 사용한다.

## 테마와 표시

- 기본 Light는 흰색 본문과 옅은 회색 사이드바를 사용한다. 설정에서 Dark와 기존 요구사항의 Solarized Light를 선택할 수 있다.
- 작은 선 아이콘, 중립적인 선택 배경, 얇은 구분선으로 탐색 요소를 표시한다. 구현 기술명은 기본 화면의 상시 상태 표시에서 제외한다.
- 파일 저장·승인·작업 상태·실행 대상 정보는 실제 backend 상태를 사용한다. 화면 정리는 backend 실행 권한이나 작업 수명 규칙을 변경하지 않는다.

브라우저·Office·자기 개선의 모든 전용 화면을 완성한 것은 아니다. 고급 RPC 패널로 접근하는 기능과 사내 환경 검증이 필요한 기능은 기존의 구현 범위를 유지한다. 사용 방법과 확인한 동작은 [Desktop 안내](../crates/desktop/README.md)에 정리한다.
