# 화면 설계 검토 초안

이 문서는 화면 배치를 논의하기 위한 제안이다. Solarized Light, 하나의 창, 대화·편집 배치 전환 등 이미 합의한 요구사항과 달리 아래의 구체적인 배치·기본값은 아직 확정하지 않았다. 화면 예시에 등장하는 프로젝트·파일·상태는 실제 실행 결과가 아니다.

## 기본 작업 화면 제안

- 왼쪽: 프로젝트별 작업 목록과 상태. 기억·응답 필요 항목은 같은 탐색 영역에서 전환한다.
- 상단: 현재 작업명, 대화·편집 전환, 세션 실행 대상과 기준 디렉토리를 표시한다. SSH 호스트와 Docker 컨테이너를 함께 표시한다.
- 대화 배치: 가운데 대화와 입력, 오른쪽 변경사항·근거·실행 탭을 둔다.
- 편집 배치: 코드 영역을 가운데 넓게 두고 대화를 오른쪽으로 옮긴다. 파일 트리를 표시한다.
- 입력 중 추가 요청의 기본은 다음 요청으로 예약이며, 안전 지점에서 현재 작업에 반영하는 옵션을 제공한다.
- 화면 전환이 실행 대상이나 작업 상태를 변경하지 않는다. 숨긴 대화·편집 영역의 입력과 위치를 보존한다.

## 이번 검토 항목

1. 처음에는 대화 배치로 열고 이후 프로젝트별 마지막 배치를 복원할지.
2. 편집 배치의 왼쪽에서 작업 목록과 파일 트리를 모두 표시할지, 탭으로 전환할지.
3. 터미널·진단·장기 작업을 하단 공용 패널로 통합할지, 작업 상세 패널에 둘지.

현재 목업은 대화·편집 전환, 상세 탭, 파일 선택, 추가 요청의 반영 시점만 탐색한다. 완성된 편집기나 실제 모델·SDK·브라우저 연결을 구현한 것이 아니다. 입력기·LSP·분할 편집·문서 미리보기·기억 관리·설정·자기 개선 상세 화면은 후속 설계 대상이다.
