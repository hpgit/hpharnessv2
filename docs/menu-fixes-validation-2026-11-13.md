## 테스트

- 데스크톱 회귀 테스트 9개 추가. 저장 승인/거부, 두 설정 편집기 왕복, 미저장 버퍼 보존, Windows/원격 경로 구분, 로컬/원격/미설치 Pyright, 파일 조회 중복과 역순 응답, 성공/실패 명령 상태, 두 충돌 해소 경로를 검사한다.
- `cargo test -p hpharness-desktop --offline`: **23개 통과**.
- `cargo clippy -p hpharness-desktop --offline -- -D warnings`: 통과.
- `scripts/test.ps1`: **전체 기본 검사 통과** — TypeScript 빌드, npm workspace 테스트, Rust workspace 테스트, Python worker 테스트. Python은 스크립트가 지정한 workspace `.venv/Scripts/python.exe`, `.tools/python`, `.cache/uv`와 uv를 사용했다.
- Worker 결과: 29개 중 2개 환경 의존 테스트 건너뜀. 기본 스크립트의 선택적 live-model/SSH/LSP 테스트도 해당 플래그 없이 건너뛴 항목이 있으므로 모두 실행했다고 해석하지 않는다.
- 수정된 소스를 별도 계측 빌드로 실행해 **41회 입력/관찰 작업**으로 위 재현 경로를 다시 검사했다. 실제 UI 이벤트, 실제 서비스, 실제 관리형 Pyright를 사용했다. 재검증 창 상태는 별도 persistence 경로로 격리했다.

## 자료와 범위

초기 발견 기록은 [메뉴 검사 결과](menu-audit-2026-11-13-results.md), 외부 캡처 장애 경위는 [초기 진단](menu-audit-2026-11-13.md)에 남겼다. 각 문서의 `.qa` 증거 경로는 검사한 로컬 워크스페이스의 자료이며 GitHub에는 게시하지 않는다.

수정 후 로컬 증거는 `.qa/menu-fix/evidence/`에 보관했다. 주요 이벤트: 설정 7/14, Pyright 18, 단일 버퍼 25, 정상 명령 상태 33, 자동 파일 조회 34, 충돌 해소 40/41. 초기 진단의 원시 캡처·실행 데이터와 계측 복사본도 `.qa/`에 남겨 두되 Git에서는 제외한다.

미지원 PDF/Office 미리보기, 미설치 언어 서버 배포, SSH/Docker 환경 구성은 이번 다섯 결함 수정에 포함하지 않았다. 테마 전환 후 스크롤 위치 변화는 원인이 확정되지 않은 별도 관찰로 남아 있다. 경로 비교는 UI 스레드에서 파일시스템 I/O를 피하는 lexical 비교이므로 서로 다른 심볼릭 링크 별칭까지 합치지는 않는다. 이미 저장돼 있던 중복 버퍼는 미저장 내용 손실을 피하기 위해 강제로 병합하지 않는다.
